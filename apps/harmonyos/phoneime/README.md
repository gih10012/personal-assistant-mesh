# 鸿蒙本机编辑确认

`phoneime` 是 `org.personalassistant.mesh` 的可选功能 HAP，只在 `ownerIme`
产品中打包。待用原应用签名构建和安装后，由机主在系统输入法设置中启用，再手动
选为当前输入法。可用标准 IME Kit 在手机的当前普通文本输入框内试填
`你好，阿米塔 👋`、选择位置 0–2 或移动一次光标。

面板显示操作内容、系统提供的应用包名和窗口号。确认按钮检查 ArkUI 报告的
触屏手指事件。一次确认自预览起 20 秒内有效，焦点解绑或重新绑定、键盘显隐、
窗口或编辑器属性改变、系统安全模式变化都会取消待确认操作。执行前再次读取
焦点编辑器的属性，只处理明确报告为普通文本且有包名和窗口号的编辑器。
成功回执表示系统编辑请求已提交，实际结果以当前输入框为准。调用异常显示
结果未知，面板消耗该确认且不会自动重试。面板收执仅在当前输入法进程内保留。

输入法内部通过 `InputClient` 执行三种操作。文字上限为 128 个 UTF-16 单元，
选择端点上限为 4096，光标一次移动一格。面板当前提供固定试填文字与选择范围。
输入法对编辑器只查询输入类型、应用和窗口属性，无按键订阅、文本读取、网络、
剪贴板或输入法切换调用。

## 接入原 Mesh 操作

商业 HarmonyOS 将 IME 扩展与主应用放在各自独立的沙箱中。华为的正式数据共享
渠道要求在 AppGallery Connect 获得「输入法应用内数据共享」和 data-group-id，
将该 ID 配置进新签发的签名 Profile 及扩展的 `dataGroupIds`。在 **BASIC** 模式
下扩展对共享沙箱仅可读，即使获批也无法写回执行回执。在 **FULL** 模式下扩展
可读写共享沙箱，须由机主通过系统设置选择，并在真机验证。此候选只提供本地试填
和编辑回执。未来获批接入时，主应用继续持有原 Mesh task / operation / allocation
和授权，向扩展交付一项有过期时间的编辑意图，扩展确认后的本地结果由正式共享渠道
关联回原操作。现有 Mesh 能力公告在真实签名、安装、授权和端到端回执前不启用本路由。
[输入法安全模式](https://developer.huawei.com/consumer/cn/doc/harmonyOS-guides/ime-kit-security/)

## 真机验收

用项目原签名挂接 `ownerIme` 产品。系统设置里，机主启用并选择「AMITA 编辑确认」。
在愿意试填的普通文本框里，点「试填中文和表情」，核对预览后手指点「点按确认」，
观察编辑器收到完整文字。然后选择位置 0–2 并移动一次光标，分别观察编辑器结果。
准备一项操作后切换文本框或收起键盘，确认旧预览失效。在已知密码编辑器验证
待确认动作无法建立。最后由机主切回常用输入法。
[IME Engine](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-inputmethodengine/)
