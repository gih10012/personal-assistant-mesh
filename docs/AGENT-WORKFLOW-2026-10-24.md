# Agent 的工作节奏与现有插件

版本：`owner-workflow-20261024-v1`。本人要求将“调查长目标执行缓慢问题”
会话中已安装的 Click 1.3.0、Codex Quota Optimizer 0.2.2、RTK 1.0.1
以及新版 niri computer-use 使用约定同步给网内 Leader、入口和项目 agent。
这是现有节点适配，不扩大为新设备自动安装项目。

## 交付先于重复确认

以用户能使用的功能结果作为阶段完成标准。已有且适用的证据直接复用，
不因为换 agent、压缩上下文或重开会话重复审查。完成一个功能后尽快在
已授权目标部署，优先做一次上层 CLI、Web 或实际 GUI 操作；通过就交付。
新增检查必须针对具体故障或重大数据/安全风险，不新建验证框架，不用
测试数量、审计文档或状态重述代替功能进展。每周集中窗口用于广泛集成、
模型比较和故障演练，不阻塞日常修复的部署与一次实用检查。

## 三个组件各做什么

| 组件 | 使用方式 | 边界 |
| --- | --- | --- |
| Click 1.3.0 | 默认 Evidence；检查经 `click-gate verify -- <原命令>`，由当前 Hook 决定执行或复用 | 不额外申请合同审批，不把记录成功当代码正确；当前宿主无法记录时如实说明，继续已授权工作 |
| CQO 0.2.2 | 定向读取、最小必要修改、复用专员结果、停止重复调查 | 不为分类另调模型，不自动运行可选 CLI/审计，不新增硬预算门 |
| RTK 1.0.1 | 支持的命令输出压缩；按返回的恢复路径读取必要遗漏 | 不限制思考次数，不宣称覆盖所有命令；仅在输出确实不可用时使用其原文回退 |

本人模型政策优先于 CQO 通用建议：常规和明确一般任务默认 Luna/max；
高级开发、架构、安全及一致性任务等待合格强模型额度，不自动降到免费
模型。插件不能修改当前 model/effort、恢复 owner pause、清 guard 或重放
unknown。独立工作仍可按既有授权并行，生产/账号/桌面写入仍串行。

安装必须适配真实节点：共享代码和说明，不复制账号、认证、会话、历史、
Click 证据缓存或本机绝对路径。Hook 需要目标宿主原生发现并信任当前
定义；文件存在、插件 enabled、实际 Hook 生效和模型核读分别记录。

## Computer-use 0.3.0

niri 后端留在实际桌面提供节点，VPS 不安装虚假的远程 Wayland 后端。
远端任务通过现有 Mesh/A2A 委派到该节点，在其权限与桌面协调下执行。
优先调用应用的 CLI/API；需要 GUI 时先 `inspect_ui(window_id)`，限定
相关控件/子树，不默认截图。优先 `perform_action`、`set_value`；AT-SPI
缺文字时用本地 `read_text` OCR，只有视觉问题或无法定位才请求局部截图。
成功反馈足够就停止，原工具保留为必要兜底。

快速判断是可选项，不新增付费 key，不复制密钥；意外结果先以
`fast_judge:false` 观察再决定。按本机已安装 Skill 执行 begin/wake/end
与亮度恢复，保持 Mod+B；不是读屏前先把屏幕点亮。

0.3.0 的桌面审批调用等待期间，保持原调用挂起，不轮询/重复提交。
遵守本人 Wait/拒绝/取消；UI 或超时暂停支持缺失就报告具体问题，不能
禁用审批、伪造输入状态或换工具规避。仅共享此约定，不声称旧执行宿主
已经具备新版审批超时暂停适配；真实 GUI 验收仍交 Leader 排队。

## 网络属于具体节点

本人明确：本机 `127.0.0.1:7890` 只服务该电脑，不传播到 VPS、手机、
Cloud 或其它节点，也不修改其它节点的代理。其它节点沿其实际网络配置
工作；传输路径和可调度出口能力分开。原生 Shell/文件/网络/MCP 保持可用。

## 生效与交接

在现有真实角色工作区添加本文件引用，保留原角色补充，不整份覆盖
AGENTS。共享源码、目标依赖、原生发现/Hook 信任及模型核读分别留实况，
不为了“读过新文档”另派模型任务、重启活跃 Worker 或绕过旧任务 guard。
下一次安全续接使用新约定，原任务、检查点、操作身份与评教暂停保持。
