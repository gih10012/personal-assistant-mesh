# 校园路径的实际边界

2026-10-10 23:10–23:17（Asia/Shanghai）只读核验：本机当前校园 Wi-Fi
连接/默认路由存在；禁用该次请求的代理，向 ncut-web-api 已确认的
校内平台公开入口发出无认证 GET，收到 HTTP 200。随后从 ali-vps
通过既有、已授权、已核验 host key 的原生 SSH 到本机执行同一个固定
探测，再次收到 HTTP 200（0.029 秒）。本机样本耗时 0.343 秒。

两个请求都在读取超过 65,536 字节后停止，结果为
`body_limit_exceeded`：**HTTP 响应已证，但完整正文/哈希和业务内容
未核验**。未使用学校 Cookie、登录或私有业务接口；未保存响应正文。
只读取目标连通性，不把校园身份自动扩成业务办理授权。

这证明一种真实可用的组合：**VPS 的 agent→原生 SSH→有校园连接的
节点→校内目标**。A2A 与 SSH 是互补入口；不要求所有能力都是网络
代理。未修改 SSH daemon、路由、DNS、Wi-Fi、全局代理或已有隧道。

它仍不是已经登记的通用校园出口、任意 HTTP/CONNECT 代理，也不是
远端浏览器已取得学校登录态。已有本机 SSH 转发政策没有为本次检查
放宽，受管 VPS HTTPS adapter 的公网合同也没有改成任意内网代理。
下一步由校园节点安装选择性能力，显式公告目标域/网络范围和时效，
经统一 discover/call/delegate/status/artifact 入口返回结果；非校内
流量继续走推荐 VPS 出口或 native 备用路径。

原生 Shell/网络/浏览器/MCP 始终可用。连通性证据按真实采样时间
计算，不因本文或目录登记续期；校园断开后由该节点 agent 自主排障、
联网和寻找 Leader。私人地址、账号与探测文件只留在私有证据目录。
