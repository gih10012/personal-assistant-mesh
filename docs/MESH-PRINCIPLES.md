# 原生自治、Mesh 能力入口、近邻代理与重汇合

这是当前目标合同和验收方向，不是已部署功能清单。沿用模型主导、Codex 原生连续上下文、开放工具创造能力。用户最终明确：任意原生 Shell、联网及其他功能不应被 Mesh 阻断；管控只应用于 Mesh 额外提供的受管能力。此前把“能力主权”扩展成全宿主强制 Broker/网络隔离的解释不适用。私人聊天、原图、身份与设备编号不进入公仓。

## 必须保留的不变量

- Mesh 内能力的发现、实际验证、登记、远端任务授权及执行证据分离；provider 声明不等于实测。这个受管入口不能被解释成拦截所有本机资源。
- 新节点首先沿加入通道建立 Mesh 通信；其他网络路径可以验证后成为受管、推荐、可调优的能力。原生联网不被禁止，也不要求每个原生请求都经过 Mesh。
- 本地 agent 保留全部原生功能，断网时自主联网、排障、尝试其他可用路径重新并网。本地 authority 管理自己的任务，未安装的离线模型不会因此可用。
- 网络断开不改变节点/能力/任务身份；重新相遇恢复可见性，不转移资源所有权，不扩大授权。旧公告不能覆盖撤销。
- 手机可以是平等自治节点，不是纯遥控器；小艺、ClawBot、Chat、Live 和面板是可替换入口，不是 Leader 的工作区或权限根。
- 没有完整 agent runtime 的外围设备可以由节点代理。发现、配对、授权、实际控制是不同证据，不能推导或相互替代。

## Mesh 入口中的网络能力分层

以下区分是受管入口的调用与审计语义，**不是宿主防火墙、原生模型功能门禁或唯一联网路径**。本机 Shell/网络保持原状；跨主体调用 Mesh 暴露的能力仍须遵循授权。

| 权限面 | 允许内容 | 不授予什么 |
| --- | --- | --- |
| Bootstrap | owner 批准的 enrollment、身份认证/续接 | 业务公网、未知 peer、自动信任 |
| Control | 已认证 peer 的心跳、账本消息、任务回执 | 任意代理 URL、业务数据隧穿 |
| Inference | 明确绑定的模型认证、推理与必要会话端点 | 通用公网抓取、第三方 API 或新付费模型 |
| Business capability | 获授权资源/动作/目标/额度内的任务操作 | 未登记或未授权资源、超范围转发 |

同一条 5G/Wi-Fi 可以承载入网、推理与业务任务，分别表达路径、成本、质量、权限和故障域，有助于调度与排障，不做“未登记前禁止任何公网包”的限制。账号凭据留在专属进程/可信凭据路径；token 不进入能力广告或模型提示。通过 Mesh 调用推理/出口时，数据范围与收费预算分别核对。

现有 laptop/cloud 使用 owner 已授权的原生 runtime。`danger-full-access`、原生终端、文件和网络不是要修复的“绕过 Mesh”缺陷；它们正是模型自主性的基础。Mesh 的授权只决定其托管 API 是否允许相应远端能力调用，不声称覆盖所有原生副作用。未来设备的本机系统权限由 owner 和平台决定，Mesh 不自行削减或提升它们。

允许模型生成任意形式的脚本、工具或插件。新增工具名不触发逐个审批或注册前置；资源登记服务于 Mesh 共享、能力选择与证据沉淀，而非限制本机执行。新增外部主体、费用或超出用户授权的副作用仍按实际任务授权判断。不会为了 Mesh 能力管控修改整台电脑的防火墙、代理或其他工作进程。

## 能力类、实例、来源与共享容量

能力类描述调用语义，实例保留 provider、目标覆盖、路径、权限及当前状态。同名实例不按名称去重；只有同一 issuer、同一实例、同一 revision 的重复公告可去重。两个出口是否可替代取决于具体目标、数据、会话和结果要求，校园内网请求不能退回仅有公网的 VPS。

未来扩展字段可用现有开放 `spec` 表达，但下表的行为仍需执行合同，不能只填元数据即算实现：

| 对象 | 最小必要关系 |
| --- | --- |
| Capability instance | class、instance、provider、来源设备、scope、revision、TTL |
| Path observation | observer、目标、路径、样本时间、有效期、证据 |
| Resource pool / failure domain | 共享瓶颈、配额、可分配容量、故障相关性 |
| Managed device | 本地私有设备身份、可核验证据，不能只靠名称/MAC |
| Proxy binding | device → provider、binding epoch、连接证据、授予范围/期限 |
| Composite capability | 已授权依赖、组合语义、当前覆盖，不能合并成超级权限 |

先过滤兼容、可达、可用、已授权和本地策略允许的实例，再用带单位/样本时间/证据的指标优化性能、费用和能耗。计算完整路径，不只测出口自身速度；共享 Wi-Fi、同 API 配额和同模型账号不能当独立容量简单相加。优先分配独立请求/任务，不声称能任意拆分单个连接的数据包。性能改善只改变选择，不增加权限。

## 近邻管理与外围设备迁移

Node neighborhood 管理认证连接、路径和局部网络视图；Device neighborhood 管理不运行 runtime 的设备发现、代理和能力撤销。物理、通信和能力邻域可以不同；耳机在手机附近不代表 PC 也能控制它。位置、蓝牙地址和扫描细节按需共享，不全网广播。

耳机、USB 设备、仅提供 HTTP/SSH 的服务都可以由节点代理，但不能因此算作选举/共识成员。来源身份保留，新 proxy 实际建立受授权连接且验证相关 API 可执行后才发布能力；旧 binding 延迟消息不能恢复过期独占权。多点连接须按真实设备能力协调，不硬编码“所有设备只有一个代理”。丢失一个外围设备不应撤销 provider 本身的其他能力。

## 同源重汇合与执行安全

软件版本、SSID、IP、Leader 名字或物理相遇不足以证明同源。未来同源判断须依赖可验证的稳定 Mesh/member 身份；陌生 Mesh 只可在明确建立信任后桥接。具体根身份、签名日志、CRDT/gossip 是实现候选，不是当前已存在的协议保证。

现有中央账本和节点自有账本各管理自己的任务与执行权。不能合并两个 SQLite 数据库就宣称安全重汇合。可合并观察/草稿逐步同步；撤销保持 issuer/revision/有效期的权威约束；高风险或独占写入有冲突时隔离。即时全局撤销与无限断网自治不能同时保证：受管 Mesh 能力的离线授权须有有限期限，过期后该入口拒绝新增对应副作用，不能无依据续租。这不暂停或封锁 agent 的原生功能、本机权限或本人另行授权的工作。

派发防重与副作用防重分离。task/attempt/operation identity、epoch 应最终由实际资源端或可信 Broker 检查；不支持幂等/fencing 的外部系统发生 ACK 丢失，继续保留 unknown，不换 ID、不因 Leader 切换重放。Leader 是协调角色，不天然拥有资源或全局无限权限；未来分片协调必须明确各自写入域，不能只比任期数字决定胜者。

## 第一批失败验收

这是一组严格验收目标。未运行是 NOT_RUN；实现缺失应得到 RED/BLOCKED，不以目录/配置/服务 active 代替结果。模拟设备仅验证协议，不冒称真实蓝牙或鸿蒙验收。

| 场景 | 最低成功证据 | 当前缺口 |
| --- | --- | --- |
| F01 断开加入通道 | 本地任务保留，agent 原生联网/排障可用，尝试重并网；远端未知任务不重放 | 多路径真实重连、离线模型尚未验 |
| F02 Mesh 入口与原生能力并存 | 未授权远端 Mesh 调用被拒绝，但原生 Shell/网络不因此失效，新工具无需白名单 | 全网入口及其执行路由须实测 |
| F03 撤销后重连/旧公告重放 | 撤销不被覆盖，不自动信任陌生身份 | 签名成员/离线日志同步未实现 |
| F04 写完成但 ACK 丢失/换 Leader | 目标真实计数最多一次或冻结 unknown | 端到端副作用对账仍需实测 |
| F05 同源设备代理迁移/迟到消息 | 来源不重复、旧 epoch 被拒绝、新连接证据有效 | Proxy binding 生命周期未实现 |

证据至少关联 test/node/task/operation/授权范围、预期、观察及 verdict。Mesh 调用拒绝与原生能力可用分别验收；外部写要检查实际目标计数。保持这些缺口可见，同时先完成当前已授权 PC↔VPS 的连接、连续上下文及回执核对，不把后续研究当成重写整个 runtime 的理由。

HarmonyOS 原生适配、系统小艺入口和 GUI/后台生命周期分别核对官方文档、签名资质与真机。聊天中的平台声明或图片解读不是本项目的验收证据。
